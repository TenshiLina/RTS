# Human faction — art references

| File | What it is |
|---|---|
| `human-female-turnaround.webp` | Concept model sheet: young woman in A-pose, front / profile / back / ¾ full body, plus front and ¾ face close-ups, neutral lighting on grey |

**This concept art is the design reference and the ideal for human characters.** The shared
character system should match it as closely as the pipeline allows: body and head proportions,
facial structure and features, hair, and the level of realism — believable, gently idealised
anatomy that is attractive and never uncanny. Models are reviewed side by side against this sheet,
in the same views.

Warcraft III Reforged is only a minimum quality bar (nothing we ship should look worse); it is
not an art direction to copy.
